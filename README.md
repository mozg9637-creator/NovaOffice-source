# Nova Office

PDF-редактор, презентации (.pptx), документы (.docx/.md/.txt/.html), печать, лента новостей. Qt (PySide6).

## Сборка
Push в `main` или Actions → `build-installer` → Run workflow. Результат: `NovaOffice-Setup.exe`
(артефакт + пререлиз `build-<N>`). Версию меняй в `app/version.py`.

## Обновления
Приложение проверяет последние успешные сборки в Actions, сравнивает номер сборки и коммит с установленными
(уже стоящую версию не предлагает), качает установщик и ставит поверх.
Установленная программа обновляется сама, в своём окне: скачивает пакет `NovaOffice-update.zip`, распаковывает,
затем короткий скрипт после выхода подменяет файлы (с копией для отката) и запускает программу заново.
Из исходников (не .exe) обновление идёт через установщик. Порядок скачивания: артефакт Actions (если в Настройках указан токен GitHub) → релиз `build-N` → nightly.link.

## Установщик
`installer/setup.py` — свой мастер (приветствие → параметры → установка → готово). Ставит в
`%LOCALAPPDATA%\Programs` без прав администратора, проверяет папку и место на диске, при ошибке откатывает
прежнюю версию, пишет журнал в `%TEMP%\NovaOffice-setup.log`, регистрируется в «Программы и компоненты».
Ключи: `/UPDATE` или `/S` — тихая установка (`/DIR=путь`, `/DESKTOP`, `/NOASSOC`, `/NOLAUNCH`),
`/UNINSTALL` — удаление (`/S` — тихо, `/PURGE` — вместе с настройками).

## Запуск из исходников
    pip install -r requirements.txt
    python app/main.py [файл]

Ctrl+K — быстрые команды, F1 — горячие клавиши, F11 — полный экран.

## Презентации
F5 — показ с первого слайда, Shift+F5 — с текущего. В показе: стрелки/пробел/колесо, Home/End, B/W — чёрный/белый
экран, L — указка, T — таймер, цифры+Enter — перейти к слайду. Есть заметки докладчика, дублирование слайда (Ctrl+D),
прямоугольник и овал.
